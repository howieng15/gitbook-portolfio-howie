# Research Projects

## Process

I usually use NotebookLM to support my research process for each project. It helps me collect, organize, and understand a large amount of information in one place.

{% stepper %}
{% step %}
### Step 1

I gather all the available project data and upload it into NotebookLM. This can include documents, notes, and any related content.

<figure><img src="../.gitbook/assets/Screenshot 2026-04-28 at 12.49.54.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Step 2

I find the website sitemap. The sitemap helps me understand the full structure of the website, including all pages and content.

<figure><img src="../.gitbook/assets/Screenshot 2026-04-28 at 12.45.47.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Step 3

I convert all the sitemap pages into markdown files. This step helps turn the website content into a clean and readable format.

<figure><img src="../.gitbook/assets/Screenshot 2026-04-28 at 12.48.06.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Step 4

I upload this combined file back into NotebookLM. With this process, NotebookLM can read and analyze all the project-related data in one place.

<figure><img src="../.gitbook/assets/Screenshot 2026-04-28 at 12.45.10.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

This helps me get a clear overview of the project, understand the structure, and support better research and decision-making.
